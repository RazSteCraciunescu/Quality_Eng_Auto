Release Readiness API

The API is intentionally small, deterministic and safe to run locally. Use the linked OpenAPI specification with Swagger Editor, Postman, SoapUI, Schemathesis or any other compatible client.

MethodPathPurpose
GET/api/healthLiveness and service metadata.
GET/api/releasesList, filter, search and sort evaluated releases.
GET/api/releases/{id}Retrieve release details and evidence.
POST/api/releases/{id}/evaluateEvaluate supplied metrics against the release gate.
GET/api/integrationsList the offline enterprise-tool samples.
POST/soap/release-readinessMinimal XML endpoint for the bundled SoapUI project.
GET/metricsPrometheus text exposition.
